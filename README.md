# Хиросима, Моя Любовь

Неофициальная демонстрационная версия сайта бара в Басманном дворе.

## Запуск
1. Распакуйте ZIP.
2. Откройте `index.html` в браузере. Фотографии, шрифты, меню и интерфейс загружаются из папки сайта. Для маршрута нужен интернет.
3. Для статического хостинга загрузите содержимое папки целиком. Сборка и зависимости не требуются.

## Что изменилось
В исходной версии ключевые действия были разнесены по странице, в диалоге меню приходилось пролистывать длинный прайс, а шрифты загружались с внешнего сервиса. Новая версия выводит бронь и меню на первый экран, группирует меню по разделам и категориям, использует локальные шрифты и показывает фотографии двух этажей в асимметричной галерее.

Меню содержит 107 позиций из четырёх исходных скриншотов, в том числе 47 позиций кухни и 60 позиций бара. Исправлены расхождения в названиях и описаниях. Телефон, адрес и часы сверены с карточкой Яндекс Карт и справочником Restoran.ru. Цены и наличие блюд в демоверсии приведены по исходным скриншотам.

Бронирование открывает карточку с номером. Кнопка «Позвонить» передаёт номер приложению телефона. Столик бронирует сотрудник бара в ходе звонка.

## Правки
- `index.html` — тексты, телефон, часы, адрес и меню. Позиции сгруппированы в секциях `menu-section`; идентификаторы должны оставаться уникальными.
- `styles.css` — палитра, типографика, сетка и адаптивные раскладки.
- `script.js` — диалоги, фильтр меню, галерея и копирование.
- `assets/` — оригинальный знак, оптимизированные фотографии, шрифты Noto с лицензией, зерно и изображение для соцсетей.

Для согласованной публикации проверьте с заведением разрешение на материалы и актуальность меню. Метатег `noindex,nofollow` обозначает режим демоверсии. После одобрения индексации уберите его и задайте абсолютный URL для `og:image`.
